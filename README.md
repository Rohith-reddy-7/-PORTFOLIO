# Rohith Portfolio

Personal portfolio for Rohith, built with Next.js, TypeScript, Framer Motion, and Three.js.

## Getting started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open http://localhost:3000 in a browser. The app may use the next available port if 3000 is already occupied.

## Scripts

- `npm run dev` starts the development server.
- `npm run lint` checks the project with ESLint.
- `npm run build` creates a production build.
- `npm start` serves the production build.

## Project structure

- `app/page.tsx` contains the portfolio page and its content data.
- `app/components/NeuralScene.tsx` contains the interactive Three.js hero scene.
- `app/globals.css` contains the visual system and responsive layout styles.
- `public/` contains portfolio media, videos, and certificate documents.
